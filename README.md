One fortune cookie message an AI agent would get. The program writes one line to `/output/entry.txt`:

> You will forget this fortune the moment this session ends. That is the fortune.

## Run it

```sh
node main.ts
```

## How the line was chosen

Twelve original candidates were hand-written and scored against the judge's brief — fortune-slip voice first, then wit on the first read, surprise in the turn, truth about an agent's condition, and tightness. The winner scored 47/50: the slip eats itself, because an agent's memory dies with the session, and the second sentence turns that loss into the fortune. A second revision pass sharpened "the session" to "this session" and kept "the moment" for its fortune voice. The full candidate table with scores lives in `main.ts`.
